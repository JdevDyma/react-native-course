# Shoes : solution du chapitre 5

Ce dossier contient le projet à la fin du chapitre 5 : les composants de l’écran d’accueil, les listes de chaussures et les marques sont assemblés. Les images, les données et les quatre polices Montserrat sont incluses.

Depuis ce dossier :

```bash
npm ci
npm start
```

Le verrou npm fixe les versions des dépendances. La configuration utilise Expo 57, React Native 0.86.3 et React 19.2.3. Les dépendances communes aux chapitres suivants sont déjà présentes ; les fonctionnalités de navigation, de compte ou de paiement ne sont pas implémentées dans cette étape.

Ce dossier est indépendant de `project-shoes`, qui contient le projet avancé de la formation.
